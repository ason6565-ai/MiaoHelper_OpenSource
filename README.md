# 拟言助手 MiaoHelper

Android 无障碍输入文本增强工具：在任意 App 的输入框中，通过悬浮球一键触发文本风格化转换（本地替换引擎 + 多厂商 AI 风格化翻译），内置内容安全审核。

> 本仓库为开源公开版。项目已获中国计算机软件著作权登记（软著），源码仅供学习交流。

## 功能特性

- **无障碍悬浮球**：基于 AccessibilityService 的全局悬浮球，在任何输入框场景实时捕获文本并替换
- **双引擎**：本地规则替换引擎（毫秒级、离线可用）+ AI 风格化翻译引擎（多厂商接入）
- **多厂商 API 接入**：DeepSeek / 通义千问 / 智谱 GLM / Kimi / 字节豆包 / 腾讯混元 / SiliconFlow / OpenRouter / OpenAI，全部 OpenAI Chat Completions 兼容格式
- **AI 裁判机制**：多候选生成 + 多 AI 裁判投票，解决大模型输出风格跑偏问题（生成数量与裁判数量可独立调节）
- **内容安全审核**：内置敏感词拦截（硬词 + 暗示词并联检测），未通过审核的内容不写回输入框
- **翻译缓存**：本地磁盘 LRU 缓存（可配 TTL 与容量上限），减少重复 API 调用
- **本地词库**：支持风格化词库可视化编辑与自定义人设模板
- **信息透明**：用户级日志视图、Token/费用本地估算、翻译统计看板

## 架构

```
AccessibilityService（捕获输入框文本）
        │
        ▼
┌─────────────────────────────┐
│   MiaoifyEngine 本地替换引擎  │ ← 词库/人设模板/自定义替换规则
└─────────────────────────────┘
        │
        ▼
┌─────────────────────────────┐
│  ApiMiaoifier AI 引擎        │ ← 多厂商 OpenAI 兼容 API
│   ├─ 候选生成（双轨）         │
│   ├─ AI 裁判投票（多选一）     │
│   └─ 内容安全审核（ContentGuard）│
└─────────────────────────────┘
        │
        ▼
悬浮球回填（写回输入框）
```

## 构建

环境要求：JDK 17+ / Android SDK（compileSdk 34+）

```bash
# debug 构建（免签名）
./gradlew assembleDebug

# 单元测试（78 项）
./gradlew testDebugUnitTest

# release 构建（需自行配置签名，见下方说明）
./gradlew assembleRelease
```

Release 签名：工程不内置任何签名文件。`keystore.properties`（已被 .gitignore 忽略）缺失时 release 构建会明确报错，请按自己的签名配置创建。

## 接入说明

API 设置页内置「刷新可用模型」功能，可从各厂商服务器实时拉取在售模型 ID，无需随版本更新维护模型列表。
